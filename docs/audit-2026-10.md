## 1. `@mlc-ai/web-llm` and `@huggingface/transformers` — lazy, verified

## 2. AI marking vs prompt injection — fenced server-side, gap on-device, FIXED

Server prompts fence every learner answer with the `<<<UNTRUSTED>>>` delimiter
(`src/ai/tasks.ts`, `untrusted()` + `UNTRUSTED_RULE` in examiner/socratic
voices, schema tariff checks in `markSchemaFor`). The on-device WebLLM prompt
(`src/ai/local-model.ts:markingPrompt`) interpolated the raw answer with no
fence — a real defect. FIXED: the fence now lives in `src/ai/untrusted.ts`
(shared so the `"use client"` module never imports server-only code),
`tasks.ts` imports it, and the local prompt fences the answer and carries the
rule. Enforcement remains schema tariffs + rubric fallback, not the fence.
New regression coverage: `tests/marking-prompt-injection.test.ts` (injection
never raises a deterministic mark; schema rejects over-tariff awards; fence
neutralises its own delimiter). Not executed here.
