# Self-hosted Inter

Unmodified normal variable WOFF2 subsets from `@fontsource-variable/inter@5.3.0`
(Inter Project Authors), distributed under the adjacent [SIL Open Font
License](OFL.txt). Upstream: https://github.com/rsms/inter;
package: https://www.npmjs.com/package/@fontsource-variable/inter/v/5.3.0.

The Latin subset is preloaded; Latin Extended supports Welsh and other European
diacritics. CSS keeps the upstream Unicode ranges and 100–900 weight range.
Both assets are cached by the service worker. Builds and browsers do not contact
Google Fonts. To update, replace the unmodified subsets and licence together,
review the Unicode ranges, and invalidate the app-shell cache.
